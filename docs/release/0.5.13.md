# ReproSec Capsule 0.5.13

Date: 2026-08-10

## Web Security Console

ReproSec now uses the SRIC Core 0.5.13 guided Security Console as its complete operational Web surface.

- The native RCAP dashboard keeps its real Inspect, Redaction preview, Timeline and Verify interactions.
- Dashboard navigation is `Dashboard / Security Console / API`.
- `Advanced Console` is removed from the user-facing navigation.
- The guided console exposes ReproSec operations through checkboxes, selectors, numeric/path controls and structured repeated-value controls instead of a free-form argv field.
- The historical `/console` route is only a compatibility alias to `/workbench`; it no longer accepts user-entered command syntax.
- Web/CLI parity remains derived from the actual Typer tree, so no public capability is invented or silently omitted.

## Security and release integration

- SRIC Core floor: `>=0.5.13,<0.6`.
- First-party runtime is pinned to GitHub-verified SRIC commit `bd90fe668e4a2a23c00a39f7d63df1c092b63c12`.
- The signed bootstrap transition chain now includes `0.5.12 -> 0.5.13` and same-version 0.5.13 repair.
- Linux/Windows installer integrity checks require SRIC 0.5.13 and retain atomic product/SRIC installation, `pip check`, shared Web import probes and quiet doctor/help smokes.
- Scope, Policy, rate limits, approval, redaction, fixed `shell=False` runner, cancellation and SSE behavior remain authoritative.

## Verification status

Regression coverage was updated for structured Web controls, absence of free-form argv UI, complete CLI/Web parameter parity, signed SRIC pinning, bootstrap transitions and installer/runtime locks.
