# ReproSec 0.5.0 Release Candidate

## Public 0.5 surfaces

CLI:

```text
reprosec research-context CONTEXT.json
```

Local API:

```text
POST /api/v1/research-context/inspect
```

The research context links RCAP evidence to Sentinel Cases, scope snapshots, policy decisions, validation recipes, tool provenance and counter-evidence. Inspection validates structure and produces a deterministic context SHA-256; it does not validate a finding.

RCAP remains schema version 0.3 in this release candidate. `spec/RCAP-0.3.md` is the formal specification and the current schema pointer now references 0.3.

## Release validation

Use the coordinated Sentinel Forge release train from sibling 0.5 checkouts. ReproSec's isolated wheel smoke resolves unreleased SRIC 0.5 from the local release wheelhouse rather than requiring prior publication.
